# 坐标轴刻度生成（从 0 实现）

起始环境只有本说明、`samples/**` 与 `.gitignore`，没有实现代码。Python 3.13、只用标准库；页面用原生 HTML/ES module，无构建无依赖；自测用 unittest、只读 `samples/**`。

## 一、范围

要做：在仓库根写刻度生成引擎 `ticks.py`（库与命令行共用同一份结果）：给数据的最小值最大值、轴长与标签宽度预算，按下面的口径选步长、算刻度与标签；再按同一份结果生成自包含页面放 `web/` 下，把轴、刻度与标签按实际宽度画出来。

不做：对数轴、时间轴、分类轴与双轴联动；网格线、图例、提示框；缩放与拖拽等交互；自定义步长；批量与并发；网络、CDN、第三方依赖与构建步骤；输入容错（`samples/**` 保证合法，非法输入按 4.2 报错）。

## 二、口径与公式

### 2.1 单位与精确性

- 轴长 `axis_length`（记 L）与标签宽度预算都以「格」计：1 格 = 一个等宽字符宽，标签宽度 w = 标签文本的字符数。
- 第 i 枚刻度在轴上 `i*L/(n-1)` 格处（i 从 0 起、n 是条数），标签居中放置、占 w 格。
- 数值按十进制精确处理：输入按字面文本解析，不得先转二进制浮点；比较、取整、格式化都用精确十进制，量程可以小到 10^-18。

### 2.2 候选步长族

    s = m × 10^k（m ∈ {1, 2, 5}，k 为整数）；同量级按 1、2、5 由小到大排

### 2.3 不变量（都是硬要求）

- 条数：`2 ≤ n ≤ n_max`，`n_max = floor(L / (max_label_width + 1)) + 1`。
- 覆盖：首刻度 ≤ 量程下界、末刻度 ≥ 量程上界；零跨度按 2.6 的有效范围核对。
- 不重叠：每枚标签宽度不超过 L；对每对相邻标签 `2*L ≥ (n-1)*(w_i + w_{i+1})`。
- `max_label_width` 只用来估条数上限；实际标签可能更宽（小数位多时就会），不重叠按实际宽度算。

### 2.4 步长选择规则

对有效量程 `[lo, hi]`，记 `span = hi - lo`：

1. 起点 `s0` 取步长族里 ≥ `span/(n_max-1)` 的最小成员；
2. 从 `s0` 起按族内从小到大逐个试，第一个三条不变量全满足的步长即选中；
3. 首刻度 `t0 = floor(lo/s)*s`、末刻度 `tn = ceil(hi/s)*s`，刻度为 `t0 + i*s`（i = 0 … n-1）：刻度值都是 s 的整数倍，首末向外取整，盖住量程；
4. 一定选得到：步长变粗时条数只减不增、小数位只减不增，足够粗时 n ≤ 3、标签只剩 `0`、`±s` 这类短文本。

### 2.5 标签格式化

记 ax = max(|min|, |max|)、an = 两个端点里非零绝对值中的较小者（两端都是 0 时 an = 0）；满足任一条就整轴用科学计数法，否则定点：

- ax ≥ 10^6；或 0 < an < 10^-4；或 an > 0 且 floor(log10 ax) - floor(log10 an) ≥ 6。
- 刻度文本：精确十进制文本、不带指数与多余尾零（如 `-60`、`0.000002`）。
- 定点模式的标签与刻度文本相同。
- 科学计数法的标签：0 写 `0`；非零刻度写 `尾数e指数`，尾数小数位取 `r = floor(log10 V) - k`（V 是刻度里最大的绝对值、k 是步长指数），去掉末尾 0，指数不带 `+` 与前导零；步长文本同这条。
- 不出 `-0` 与浮点尾巴（如 `0.30000000000000004`）。

### 2.6 零跨度与跨零

- 跨零：量程含 0 时 0 必是其中一枚刻度（0 一定是 s 的整数倍）。
- `min == max == v` 时先把有效范围换成 `[v-u, v+u]`：v ≠ 0 时 u = 10^floor(log10|v|)，v = 0 时 u = 1，其余规则照旧（v = 7.5 → [6.5, 8.5]；v = 0 → [-1, 1]）。负值标签带 `-` 号。

## 三、数据结构与流程

引擎放仓库根 `ticks.py`，库与命令行共用同一份结果，公开 API 名自定。输入记录是 `min`、`max`（精确十进制）、`axis_length`、`max_label_width`（整数格）；刻度表 n 条，每条含值、刻度文本、标签、标签宽度、轴上的位置。流程：读入 → 零跨度时换有效范围 → 算 `n_max` → 定起点 `s0` → 逐个试候选 → 取首末刻度并展开 → 格式化 → 写 JSON 或页面。

## 四、输入输出与文件格式

一律 UTF-8、LF、末行有换行。

### 4.1 输入 `samples/ranges/*.json`

四个键都必给：`min`、`max` 是十进制数；`axis_length` 是 ≥ 2 的整数；`max_label_width` 是整数且 8 ≤ `max_label_width` ≤ `axis_length`。

### 4.2 命令行

    python ticks.py solve <量程.json> <结果.json>
    python ticks.py page  <量程.json> <页面.html>

`page` 的产物提交时放 `web/index.html`（用 03 号样例生成）。参数不对、文件不存在或内容不合法时，向 stderr 打印一行 `error:` 开头的说明、退出码 2，不写输出。

### 4.3 `solve` 的输出 JSON

    {"step": "20", "count": 3, "ticks": ["-20", "0", "20"], "labels": ["-20", "0", "20"]}

`step`、`ticks`、`labels` 都是文本，顺序与刻度一致，`count` 与数组长度一致。

### 4.4 期望文件 `samples/expected/*.txt`

首行 `step <步长文本>`、次行 `count <条数>`，其后每枚刻度一行 `<刻度文本> <标签文本>`（单空格分隔、行尾无空格）；与 `ranges` 同名成套，顺序敏感。

### 4.5 页面

自包含、双击可开、不引外部资源、不 `fetch`，脚本用原生 ES module，必须含：`<pre id="ticks">`（每枚刻度一行 `<刻度文本> <标签文本>`，与 4.4 的刻度行逐行一致）；顶部一个 `id="axis-summary"` 元素（文本里带 `step=<步长文本>` 与 `count=<条数>`）；画出来的轴（内联 SVG 或等宽网格都行）里，刻度与标签按 2.1 的位置与实际宽度摆放，重叠的相邻标签标红。页面数字只能来自引擎输出，不重算、不带时间戳之类易变内容。

## 五、性能与验收口径

预算：单次 `solve` 或 `page`（含解释器启动）不超过 5 秒，峰值常驻内存不超过 128 MiB。

1. 逐组 `python ticks.py solve samples/ranges/<名>.json var/<名>.json`，退出码 0；输出的 `step`、`count`、`ticks`、`labels` 与 `samples/expected/<名>.txt` 逐条一致（顺序敏感）。
2. 逐组 `python ticks.py page samples/ranges/<名>.json var/<名>.html`，退出码 0；`<pre id="ticks">` 与期望文件的刻度行逐行一致；页面不含外部资源。
3. 逐组核对三条不变量（条数、覆盖、不重叠）、每枚标签宽度 ≤ L、步长落在族里、每枚刻度值是步长的整数倍（精确十进制）。
4. 确定性：同一份输入连跑两遍，再换 `PYTHONHASHSEED=0/1/2` 跑，`solve` 与 `page` 输出逐字节相同。
5. 环境：只用标准库、不联网、无构建；`python -m unittest` 能跑通，测试只读 `samples/**`。
6. 不许写死：不得读 `samples/expected/**`、不得按样例名或量程特判；评测会换量程、轴长与宽度预算。
